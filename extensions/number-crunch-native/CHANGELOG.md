# Changelog

All notable changes to Number Crunch are documented here.

## 1.1.0 — 2026-08-22

### Added
- To KB, To MB, and To GB convert any file size to a chosen SI unit.

## 1.0.0 — 2026-08-22

Initial public package identity: `com.ibuhs.vehla.number-crunch`.

### Added
- QuickGlass actions for selected numbers: Sum Numbers, Average, Evaluate,
  To Metric, To Imperial, Humanize Size, and To Bytes.
- Off-main-thread math so Vehla stays responsive.
- A compact reference workspace that lists the QuickGlass actions.
