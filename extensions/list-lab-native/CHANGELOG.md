# Changelog

All notable changes to List Lab are documented here.

## 1.0.0 — 2026-08-22

Initial public package identity: `com.ibuhs.vehla.list-lab`.

### Added
- QuickGlass actions for selected lists: Comma to Lines, Lines to Comma,
  Pipe to Lines, Lines to Pipe, Shuffle Lines, Number Lines, Quote Lines,
  Wrap (), Unwrap, and Prefix with Clipboard.
- Off-main-thread transforms so Vehla stays responsive.
- A compact reference workspace that lists the QuickGlass actions.
