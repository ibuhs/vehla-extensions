# Changelog

All notable changes to Reading Tools are documented here.

## 1.0.1 — 2026-08-22

### Added
- Dedicated QuickGlass actions for word and character counts and estimated
  reading time.
- A scrollable, selectable Large Type view for selected text.

## 1.0.0 — 2026-08-22

Initial public package identity: `com.ibuhs.vehla.reading-tools`.

### Added
- QuickGlass actions for reading statistics, reading time, readability, grade
  level, sentence analysis, and estimated syllable counts.
- Deterministic local analysis on an actor so Vehla stays responsive.
- A compact reference workspace for the available actions.
