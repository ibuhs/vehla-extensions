# Changelog

All notable changes to Type Polish are documented here.

## 1.0.0 — 2026-08-22

Initial public package identity: `com.ibuhs.vehla.type-polish`.

### Added
- QuickGlass actions for selected prose: Straighten Quotes, Clean Dashes,
  Unwrap Lines, Collapse Spaces, Strip Invisible, and Polish Text.
- Off-main-thread transforms so Vehla stays responsive.
- A compact reference workspace that lists the QuickGlass actions.
