# Wallhaven Notch

A Notch / Island extension (Store API 4). Adds a **Wallhaven** tab to the open Notch:
search, sort, page through SFW wallpapers, then Set as Wallpaper, Open, or Copy Link.
Setting a wallpaper shows a live activity in the closed Notch.

Turn it on in Vehla Settings > Notch / Island. Build with `./build.sh` and install `dist/Wallhaven Notch`.
