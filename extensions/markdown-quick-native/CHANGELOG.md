# Changelog

All notable changes to Markdown Quick are documented here.

## 1.0.0 — 2026-08-22

Initial public package identity: `com.ibuhs.vehla.markdown-quick`.

### Added
- QuickGlass actions for selected Markdown: Normalize, Strip, Format Tables,
  Links to URLs, Extract Links, and Extract Headings.
- Off-main-thread parsing so Vehla stays responsive.
- A compact reference workspace that lists the QuickGlass actions.

### Notes
- Table formatting supports GFM pipe tables.
- Created with AI assistance; reviewed by a human before release.
