# Changelog

All notable changes to Data Extractor are documented here.

## 1.0.0 — 2026-08-22

Initial public package identity: `com.ibuhs.vehla.data-extractor`.

### Added
- QuickGlass actions for selected text: Extract Emails, Extract Phones,
  Extract IPs, Extract Mentions, Extract Hashtags, Extract All, and Extract CSV.
- Off-main-thread parsing so Vehla stays responsive.
- A compact reference workspace that lists the QuickGlass actions.
